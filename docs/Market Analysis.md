# Аналіз ринку альтернатив

* **Месенджери та особисті домовленості (напр. Gmail, Telegram, Viber):** Процес розподілу залишається хаотичним. Студенти пишуть влітку, на початку року або судорожно після закінчення строків.
* **Університетські LMS (напр. Moodle, Google Classroom):** Не підтримують спеціалізовані часові стадії: період домовленостей тільки попереднього бронювання, створення загального пулу, розподіл та фінальні коригування. Відсутній загальний огляд викладачів та їх наукових інтересів.
* **Український ринок EdTech (напр. ЄДЕБО):** Виконують функцію глобального державного обліку. На українському ринку відсутні спеціалізовані сервіси для внутрішньоуніверситетського вибору керівників.

# Чим власна система краще зазначених альтернатив

* **Автоматизація хаосу:** Система автоматизує розподіл за заданими критеріями зі сторони викладачів та студентів.
* **Точний метчинг:** Враховуються наукові інтереси обох сторін, запити на співпрацю з конкретними викладачами/студентами та ліміти вільних "слотів".
* **Мінімізація бюрократії:** Автоматична генерація заяв з експортом для підпису. 
* **AI-потенціал:** Архітектура передбачає розширення через ембединги: семантичний пошук за темою, запобігання дублікатам та категоризацію минулорічних робіт.
